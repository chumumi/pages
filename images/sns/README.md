# SNS Icons

このディレクトリに以下の画像ファイルを配置してください。

## 必要なファイル一覧

| ファイル名 | 推奨サイズ | 説明 |
|-----------|---------|------|
| `github.png` | 80x80px以上 | GitHubロゴ |
| `twitter.png` | 80x80px以上 | Twitterロゴ |
| `linkedin.png` | 80x80px以上 | LinkedInロゴ |
| `email.png` | 80x80px以上 | メールアイコン |

## 推奨事項
- 背景透過のPNG形式を推奨
- 正方形の画像を使用（80x80px程度）
- テーマカラー（#32B840）に合わせたデザインが良好

## 使い方
1. 各SNSのロゴ/アイコンを取得
2. ファイル名を上記の名前に変更
3. このディレクトリに配置

### href属性の設定
index.htmlの各リンクの `href` 属性を以下のように設定してください：
- GitHub: `https://github.com/ユーザー名`
- Twitter: `https://twitter.com/ユーザー名`
- LinkedIn: `https://linkedin.com/in/プロフィール`
- Email: `mailto:メールアドレス`
